About

The person behind
the endpoints

Hello. I'm Bismark Obuobi, a final-year BSc Information Technology student at the University of Ghana, Legon, with a burning passion for software development and system design.

I have real experience on the frontend — ReactJS and React Native — but my calling is architecting robust backend systems. I build scalable APIs with Node.js and Express, and I work comfortably across both SQL and NoSQL databases depending on what the data actually looks like.

The move from frontend to backend wasn't a pivot so much as a descent. I kept following the request: from the button, through the network, into the handler, down to the query, and finally to the row on disk. Each layer explained the one above it, and I wanted the whole picture.

So I'm still going down. Constantly learning, constantly building, pushing towards becoming a world-class software engineer — which mostly looks like reading other people's post-mortems and redesigning my own schemas at midnight.
