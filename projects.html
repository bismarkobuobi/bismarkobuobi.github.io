01

Shaggysco Pharmacy

Full stack  ·  React, Express, Prisma, PostgreSQL

An online storefront and a staff dashboard for an over-the-counter chemist on the first floor of Naa Plaza Building, Okaishie — a real client, with real shelves and an owner who notices immediately if the delivery fee is wrong. Three applications on one server, sharing a typed domain package so the two frontends can never disagree about what an order status means.

There is no stock column. Stock is derived from the batches that actually arrived, each with its code and expiry, so a recall can be answered by batch number and expired boxes stop counting at midnight without anybody remembering to do anything.

React TypeScript Express Prisma PostgreSQL Paystack SMS
  • Catalogue, basket and checkout — card, mobile money, cash on delivery
  • Batch and expiry tracking in place of a stored stock count
  • SMS on dispatch, order alerts to the shop
  • Caddy with automatic TLS, systemd, database bound to localhost
Live shaggyscopharmacy.com
02

Multitenant E-Commerce Platform

Backend  ·  Node.js, Express, PostgreSQL

A secure, scalable backend for a multitenant e-commerce web application, where users browse and purchase products from multiple vendors across a single platform. Every request carries a tenant context, and every query is scoped by it — because the expensive bug in multitenancy is the one where two vendors can see each other.

Node.js Express PostgreSQL Multi-tenancy RESTful API
  • Multi-vendor support
  • Secure authentication & authorisation
  • Product browsing & purchase system
  • Scalable architecture
Hosted farmgh.com — not in full operation
03

UG Gym Subscription System

Backend  ·  Node.js, Express, MongoDB

The backend for the University of Ghana Gym's subscription management system. It digitalises what used to be a manual, in-person process, so members can purchase and manage their subscriptions online, at any hour, from anywhere. Payments are the part that has to be right on the first attempt — and on the retry.

Node.js Express MongoDB Payment integration Subscription management
  • Online subscription purchase
  • Subscription management system
  • User authentication
  • Eliminates manual processing
